💡 Help & Documentation

Welcome to CRBot! Here is a quick guide on how to interact with it.

1. General

By default, you are connected to a small sample database called KitchenBank as a user called BankClerk that you may use as playground.

If you prefer to use your own database, click the gear icon on the upper right corner to configure your connection.

2. Natural Language Query

Type your query or instruction into the top text box in plain English or any other language. Click Translate Prompt to preview the generated SQL statement.

Example queries: "find all accounts with more than $5000", "give Mike $100", "allow Dary to browse client data", "Show all users created last week".

3. SQL Query

Review the SQL in the middle editor box. You can manually edit the statement or write custom queries from scratch. Click Execute SQL to run the command against your database.

4. 'I feel lucky' Mode

Clicking I feel> lucky will automatically translate your natural language prompt and execute the resulting SQL in one seamless step. Use this mode judiciously.

5. Selecting AI Model

By default, the application uses Gemini 3.6 Flash. You can change that in the configuration popup (gear icon).

The quota of the default Gemini API Key may be exchausted. In the case, use the configuratiom popup to select an alternative bundled key or enter your own.
